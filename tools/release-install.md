## Install

**Requirements:** Windows 10/11, Windows Terminal, Windows PowerShell 5.1 (built in), Claude Code (`claude` on PATH), Git and Visual Studio Code. The installer stops with instructions if Git or VS Code is missing.

1. Download **Source code (zip)** below and extract it somewhere permanent (for example `C:\tools\workspace-wrangler`). Or `git clone https://github.com/dstaulcu/workspace-wrangler.git`.
2. In that folder run: `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-Shortcut.ps1`
3. Double-click **Workspace Wrangler** on your Desktop. While it is open, **Ctrl+Alt+W** cascades all open workspaces.

**Already installed?** The picker offers this release itself: click **Update now**. Settings are kept.
